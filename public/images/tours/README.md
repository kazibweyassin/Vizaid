# Tour Images Directory

Place tour images in this directory. The following images are expected:

## Domestic Tours
- `gorilla-trekking.jpg` - Gorilla Trekking Adventure
- `queen-elizabeth.jpg` - Queen Elizabeth Safari
- `murchison-falls.jpg` - Murchison Falls Experience
- `chimpanzee-trekking.jpg` - Chimpanzee Trekking
- `rwenzori-mountains.jpg` - Rwenzori Mountains Hike
- `source-of-nile.jpg` - Source of the Nile Tour

## International Tours
- `dubai.jpg` - Dubai City Break
- `paris-london.jpg` - Paris & London
- `cape-town.jpg` - Cape Town Adventure
- `thailand.jpg` - Thailand Discovery

## Image Requirements
- Recommended size: 1200x800 pixels or larger
- Format: JPG or PNG
- File size: Optimize to under 500KB for web performance
- Aspect ratio: 3:2 or 16:9 works best

## Adding Images
1. Add your images to this directory with the filenames listed above
2. The images will automatically be displayed on the tour detail pages
3. If an image is missing, a placeholder emoji will be shown
